# Conduit.Transport.AmazonSqs

User guide: [`docs/transports/amazon-sqs.md`](../../docs/transports/amazon-sqs.md) — setup, options, configuration keys, credentials, LocalStack, topology, pools, wire format. Keep user-facing facts there, not here.

- `AmazonSqsTransport` — extends `BrokerTransportBase<AmazonSqsInboundMessage>`. Uses AWS SDK (`AmazonSNSClient` + `AmazonSQSClient`). Inbound dispatch, lifecycle, and outbound serialization handled by base class. Implements SNS/SQS-specific primitives: SNS publishing, SQS long-polling consumers, the reply-queue poller (which hands each reply to the base class's `CompleteReply`), topology creation.
- `UseAmazonSqs(configure?)` registers everything **keyed by endpoint name** — options, `AmazonSqsTransport` (via `ActivatorUtilities.CreateInstance`, resolving the keyed options), a forwarding non-keyed `IConduitTransport` entry and a forwarding non-keyed `IHostedService` entry (each resolving the endpoint's keyed transport instance) — and calls `UseTransport<AmazonSqsTransport>()`. No non-keyed `AmazonSqsTransport`/options registration exists. No connection string — Region or ServiceUri.
- **The 10-attribute ceiling drives the wire format.** SNS/SQS cap a message at 10 message attributes and a request publish already uses 9 (`Type`, `MessageId`, `CausationId`, `ConversationId`, `traceparent`, `tracestate`, `conduit-source-app`, `ReplyQueueAddress`, `CorrelationId`), leaving **one** spare. The three correlation ids are therefore **renamed** from their canonical `conduit-*` keys rather than duplicated alongside them — see `BuildOutboundAttributes`/`ToAttributeName`. Adding another always-on attribute needs a plan for what comes off.
- **Raw message delivery is load-bearing, not a preference.** SNS filter policies match on message attributes, and attributes are only visible to a policy under raw delivery; without it SNS wraps the payload and every queue receives every message. Startup validates `RawMessageDelivery == true` and `VisibilityTimeoutSeconds >= ResponseTimeout` (a shorter visibility timeout redelivers a message while its caller still awaits the reply).
- SQS queue name limit is 80 characters — `TopologyNaming` hash truncation activates frequently here, more than on any other transport.
- `AmazonSqsTopologyReaper.ReapByPrefixAsync(options, prefix)` — public best-effort cleanup deleting SQS queues + SNS topics by name prefix (deleting a topic removes its subscriptions). The prefix is sanitized first (`ResourceNamePrefix` = `TopologyNaming.Sanitize`), as resource names are: a raw `john.doe` matched none of the `john-doe-…` names (`Unit.AmazonSqsTopologyReaperShould`). Used by the test harness once per project; also available to apps. SNS/SQS clients come from the shared `AmazonSqsClientFactory`, also used by `ConnectAsync`.
- `DefaultConcurrency` / `ReceiverPoolOptions.Concurrency` map to the polling parallelism bound (the per-consumer `SemaphoreSlim` limit). The semaphores are fields (`pollerSlots`), disposed in `DisposeAsync`, never a `using` in the poll loop: a handler releases its slot after its poller has stopped (`ReleaseSlot` tolerates a slot disposed under a handler the shutdown deadline cut short). Handlers run in `Task.Run` with no token, so a message holding a slot always runs (or is handed back by the base class while draining).
- Stop: the app/pool pollers (`inboundPolling`) and the reply poller (`replyPolling`) have separate tokens. `StopReceivingAsync` cancels and awaits the inbound pollers only; the reply poller keeps running through the drain and stops in `StopConsumersAsync`. `DisposeAsync` is idempotent: the keyed registration and both forwarders resolve the same instance, and the container disposes what each factory returns.
- Type discovery via `ConduitTypeRegistry` (source-generated, compile-time verified) — no runtime DI scanning.
- `Region` and `Credentials` are **excluded** from `ConduitConfigurationBinder.BindTransportOptions` and hand-mapped in `ApplyAwsConfiguration`: the binder resolves `RegionEndpoint` to null silently and throws outright on the abstract `AWSCredentials`. An incomplete `AccessKey`/`SecretKey` pair falls back to the default AWS credential chain.
